# 📊 Student Performance Analyzer

A Python-based data analysis project developed during the QSkill Python Development Internship.

This project analyzes student academic performance by calculating total marks, averages, grades, pass/fail status, rankings, subject-wise performance, and visual insights.

---

## 🚀 Features

- Calculate total marks
- Calculate average marks
- Assign grades automatically
- Analyze pass/fail status
- Identify the top-performing student
- Rank students based on average marks
- Perform subject-wise average analysis
- Identify the best-performing subject
- Search students by name
- Display complete student performance reports
- Save data to CSV
- Load data from CSV
- Generate bar charts
- Generate pie charts
- Create class performance summaries

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

---

## 📊 Analysis and Visualizations

The project includes:

### Subject-wise Average Analysis
Compares average marks across different subjects.

### Grade Distribution
Shows the distribution of grades among students.

### Pass/Fail Analysis
Visualizes the percentage of students who passed and failed.

### Student Ranking
Ranks students based on their average marks.

### Class Performance Summary
Displays important class-level performance metrics.
