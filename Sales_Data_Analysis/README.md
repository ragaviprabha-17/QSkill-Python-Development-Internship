# 📊 Sales Data Analysis Dashboard

A Python-based sales data analysis project developed during the QSkill Python Development Internship.

This project analyzes sales data to identify revenue trends, top-selling products, best-performing categories, regional performance, and sales distribution using Python, Pandas, and Matplotlib.

---

## 🚀 Features

- Calculate sales amount
- Calculate total revenue
- Analyze product-wise sales
- Identify the best-selling product
- Analyze category-wise sales
- Identify the best-performing category
- Analyze region-wise sales
- Identify the best-performing region
- Analyze monthly sales trends
- Find the highest-selling transaction
- Analyze products by quantity sold
- Calculate product revenue contribution
- Save sales data to CSV
- Load sales data from CSV
- Generate multiple visualizations

---

## 📊 Visualizations

The project includes:

### 📈 Monthly Sales Trend
Displays changes in sales revenue over time.

### 📊 Product-wise Sales Bar Chart
Compares revenue generated by different products.

### 🥧 Category-wise Sales Pie Chart
Shows the percentage contribution of each category to total sales.

### 📊 Sales Amount Histogram
Shows the distribution of sales transaction amounts.

### 🌍 Region-wise Sales Chart
Compares revenue across different regions.
