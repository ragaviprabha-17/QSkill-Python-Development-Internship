# 📚 Library Management System

A Python-based Library Management System developed during the QSkill Python Development Internship.

## 🚀 Features

- View all books
- Add new books
- Search books by title
- Search books by category
- Search books by author
- Issue books
- Return books
- Track borrower information
- View library statistics
- Save data to CSV
- Load data from CSV

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

## ▶️ How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run all cells from top to bottom.
3. Start the menu.
4. Choose options from the menu.
